AI科研论文评估与可信度核查系统

该项目已完成 React 前端与 FastAPI 后端的真实 HTTP 联调：前端提交论文来源并轮询任务状态；后端提供解析、模型调用、证据校验和结构化报告接口。

当前线上状态

团队前端、后端和数据基准仓库仍为私有协作仓库，尚未配置可公开访问的部署服务。因此这里不放合成论文或预设报告来冒充线上产品。

真实模型模式需要部署端保存 DeepSeek API 密钥，并且目前只支持受限样本 2307.08122v3。后端说明也明确标注当前本机单实例版本不适合直接公开发布。

实际接口范围

  • 前端：论文输入、模型与会议选项、进度轮询、证据侧栏和错误重试。
  • 后端：/health、/v1/models、/v1/assessments 等真实 HTTP 接口。
  • 真实样本：使用 DeepSeek 与受限 Benchmark 解析链路；通用论文解析仍未开放。
